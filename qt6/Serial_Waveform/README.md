# 串口波形显示工具

基于 Qt6 的串口数据波形显示软件，支持实时波形绘制和滤波处理。

## 功能特性

- **串口通信**：支持多种波特率（9600 ~ 921600）
- **实时波形显示**：自动滚动显示，可调整时间窗口
- **双波形对比**：同时显示原始波形和滤波后波形
- **多种滤波算法**：
  - 移动平均（Moving Average）
  - 指数移动平均（EMA）
- **实时参数显示**：当前值、滤波值、最小值、最大值、平均值、数据点数
- **自定义数据协议**：支持单值、带时间戳、多通道格式

## 编译运行

### 依赖

- Qt 6.x（需要 Widgets 和 SerialPort 模块）
- CMake 3.16+
- C++17 编译器

### 编译步骤

```bash
cmake -B build -S .
cmake --build build
```

### 运行

```bash
./build/Serial_Waveform
```

## 数据协议

软件支持 ASCII 格式的串口数据，每行一个数据点，支持以下格式：

### 1. 单值格式

```
123.45
-67.89
0.5
```

自动分配时间戳（假设 10ms 间隔）

### 2. 带时间戳格式

```
timestamp,value
0,100.5
10,101.2
20,99.8
```

时间戳单位为毫秒

### 3. 多通道格式

```
timestamp,ch1,ch2,ch3
0,100.5,200.3,300.1
10,101.2,201.5,301.2
```

每个通道会分别显示（通过时间戳偏移区分）

## 使用说明

1. **连接串口**：
   - 选择串口端口（点击"刷新"按钮可重新扫描）
   - 选择波特率
   - 点击"连接"按钮

2. **配置滤波器**：
   - 选择滤波类型（无/移动平均/指数移动平均）
   - 调整滤波参数：
     - 移动平均：调整窗口大小
     - EMA：调整 Alpha 值（0~1，越大越敏感）

3. **调整显示**：
   - 设置时间窗口（显示多长时间的数据）
   - 开启/关闭自动滚动
   - 点击"清空数据"清除所有数据

4. **查看参数**：
   - 实时参数区域显示当前值、滤波值、统计数据等

## 扩展开发

### 添加新的滤波算法

1. 在 `FilterEngine.h` 中添加新的 `FilterType` 枚举
2. 在 `FilterEngine::process()` 中实现新的滤波逻辑
3. 在 `MainWindow::onFilterTypeChanged()` 中添加对应的 UI 控制

### 修改数据协议

修改 `SerialManager::parseLine()` 方法以支持自定义协议格式。
