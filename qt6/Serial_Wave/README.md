# Serial Wave

Qt 6 品质指标、电机及电动推杆监测、采集与历史回看工具。CAN 通过 Qt SerialBus 接入，
Linux 使用 SocketCAN，Windows/macOS 使用 PCAN-USB（peakcan 插件）。

## CAN 品质报文

**Linux**：在系统中配置并启用 SocketCAN 接口（例如 `can0`），波特率须与发送端一致。
**Windows**：安装 PEAK 官方驱动（含 PCANBasic.dll），接口名填 `usb0`（对应 PCAN_USBBUS1）。
**macOS**：安装 [MacCAN PCBUSB 库](https://github.com/mac-can/PCBUSB-Library)（≥0.9），接口名同样填 `usb0`，
波特率在程序内设置。Windows/macOS 上连接时程序会把所填波特率写入 PCAN 通道。

在程序中选择“传感数据接收 → CAN 总线”，填写接口名后点击“连接”。采集端只接收所选 ID 的经典 CAN 标准数据帧。
默认 ID 为 `0x123`（十进制 291）。如果发送端使用十进制 123，在“接收 ID”中填 `123`，
相当于 `0x07B`。带 `0x` 的输入按十六进制读取。

Linux 上 CAN 配置栏会显示系统接口是否已启用；系统装有 `ip` 且可以读取 CAN 配置时，波特率也会显示在此处。
接收流量和最近接收时间只统计所选 ID 的帧，每次连接时清零。

| 字节偏移 | 内容 |
| --- | --- |
| 0～3 | 含杂率，IEEE 754 float32，小端，原始比例 0～1 |
| 4～7 | 破碎率，IEEE 754 float32，小端，原始比例 0～1 |

数据区固定 8 字节。含杂率 3%、破碎率 2% 的有效载荷为 `8F C2 F5 3C 0A D7 A3 3C`。
收到有效帧后，程序按百分数显示、统计和记录两项指标。转速和推杆反馈在 CAN 会话中显示为
缺失值，导出 CSV 时留空，JSON 中为 `null`。

## 串口协议

在“传感数据接收”中选择“串口”可接收原设备的品质、转速及推杆反馈。原串口品质帧：
`FF + 4 个小端 float（破碎率比例、含杂率比例、实际转速、目标转速）+ EE`，共 18 字节。
前两项传输 `0～1` 的原始比例，例如 `0.021` 表示 `2.1%`；后两项单位为 rpm。
上位机在解析时将比例乘以 100，波形、状态、均值、会话记录及 CSV/JSON 导出均使用百分数。
旧帧的长度、字节序和帧头帧尾保持不变；推杆使用下文的可选扩展帧，两者均未增加 CRC。

此单位约定需要与发送原始比例的固件配套使用；旧版直接发送百分数的固件需同步更新，
不能靠数值大小自动区分两种协议。已有 `.swave` 历史记录仍按百分数回看，不再乘以 100。

## 基本使用

1. 在“传感数据接收”中选择接收方式并连接，程序自动开始记录。控制台连接在“控制台配置”中单独设置。
2. 三幅图依次显示品质指标、电机实际/目标转速、推杆行程百分比，共用底部时间刻度。
3. “冻结显示”只冻结视图，记录继续；拖动、滚轮缩放也会自动冻结。
   “回到最新”恢复跟随。窗口可选 5、10、30、60 秒。
   Ctrl+滚轮可缩放 Y 轴，Shift+拖动可平移 Y 轴；手动调整 Y 时关闭 Y 自适应。
4. 鼠标在波形中移动可读出采样值。“区间统计”计算当前可视时间范围内的
   **全部原始已记录数据**的均值、最小值、最大值和总体标准差。
5. “停止记录”结束当前文件的追加，实时监测继续；“开始记录”创建新文件。
   “新建会话”保存当前记录并创建新文件，同时重置时间、计数、均值和速率基线。
   旧会话始终保留。
6. 断开传感连接会停止并保存记录。再次连接会新建会话。
7. 断开传感连接后，通过“打开会话…”载入 `.swave` 文件，再拖动、缩放查看。
   历史文件以只读方式打开；“回到最新”跳到文件末尾。
8. “文件 → 选择记录保存目录…”设置后续会话的目录；“记录目录”打开当前文件所在目录。
   “文件 → 会话另存为…”复制当前会话，并将后续记录切换到新文件。

通信配置、保存目录、导出目录、自动导出选项、波形窗口、Y 自适应、窗口与日志布局会保留。
默认窗口目标尺寸为 1700 × 1300，并按屏幕可用区域限制大小，为三幅波形提供更多高度。
旧窗口配置会在首次升级时增加高度，之后继续记住用户调整；恢复默认布局也会增加到默认高度。
控制台默认停靠右侧，初始宽度随窗口大小在 380～520 像素间调整，可拖动边界调整并保留布局。关闭后可通过顶部“控制台”按钮、
“视图 → 控制台”或 Ctrl+L 重新打开；“恢复默认布局”可重置右侧停靠与三幅图的高度。
串口配置下方显示本次连接的原始接收字节、实际写出字节和最近接收时间；连接成功后清零。
查看旧日志时，新日志不会强制滚回底部。
命令输入支持上下箭头或“历史”菜单查看本次运行的最近 50 条已成功排队命令；发送失败时保留输入。

## 波形定位与 A/B 分析

- “查看全程”冻结显示并展开当前会话全部已记录时间；“定位时间”输入主机接收秒数，
  点击“跳转”居中查看，三个时间轴同步。超出已有数据范围不会跳转。
  没有归档数据时，“查看全程”只显示仍在实时缓冲里的数据，不恢复已丢弃缓存。
- 打开“A/B 测量”，在任意一幅波形里依次单击 A、B，第三次单击重新选择 A。
  标线和所选区间在三幅图同步显示。A/B 自动吸附到最近的**原始已记录采样**，
  等距时选更早时间；不按抽稀显示点取值，也不插值或跳过缺失反馈去寻找其他时刻的值。
  屏幕上的鼠标悬停读数仍来自绘图保留点，与 A/B 原始记录查询有区别。
- “测量详情”显示五路通道的 A、B、差值 B−A，以及闭区间内全部原始记录的最小值、
  最大值、均值、总体标准差及各通道有效点数。B 可在 A 之前，时间差仍显示 B−A，
  统计范围则使用两点的较早到较晚时间。缺失值显示 `--`，统计忽略缺失值。
  A/B 可能跨越停止上报的间隔，时间差包含该间隔，不代表连续采样时长。
- 测量查询和区间统计在后台进行；采集和保存继续。快速重新选点、清除测量或切换
  会话会取消旧查询，完成中的旧结果不会写回新会话。清理历史会话也保护测量读取中的文件。
- “导出 A/B…”仅导出两点闭区间内的原始已记录数据，支持 CSV/JSON、进度与取消。
  时间仍是原会话时间，不从零重排；JSON 额外包含 `range_start_s` / `range_end_s`。
  缺失推杆反馈与状态仍导出为空/`null`；没有记录数据的区间不会创建导出文件。
- 测量模式下左键用于选点；关闭“A/B 测量”后恢复拖动，已选区间仍保留。
  “清除测量”清除标线并可重新选点；恢复跟随、新建或打开其他会话会清除测量。
  “区间统计”仍统计当前可视范围，A/B 区间统计在“测量详情”里查看。

## 电动推杆与串口扩展帧

推杆行程显示 0～100%：0% 完全缩回，100% 完全伸出。状态卡片显示设备反馈的停止、
伸出中、缩回中、完全缩回、完全伸出、故障或未知状态；不根据行程数值猜测运动状态。
仅收到原来的四路旧帧时，推杆显示“暂无数据”，曲线不画成 0%。断线和数据过期会置灰。

为尚未定义推杆协议的固件提供以下**可选上报格式**，原 18 字节帧无需修改：

| 字节偏移 | 内容 |
| --- | --- |
| 0 | 帧头 `FE` |
| 1～4 | 破碎率，float32 小端，原始比例 0～1 |
| 5～8 | 含杂率，float32 小端，原始比例 0～1 |
| 9～12 | 实际转速，float32 小端，rpm |
| 13～16 | 目标转速，float32 小端，rpm |
| 17～20 | 推杆行程，float32 小端，直接填写 0～100 百分数 |
| 21 | 推杆状态，uint8 |
| 22 | 帧尾 `EE` |

状态代码：`0` 未知、`1` 停止、`2` 伸出中、`3` 缩回中、`4` 完全缩回、`5` 完全伸出、`6` 故障。
非有限数、超出 0～100 的行程、未知状态代码或错误帧尾会被拒绝。
新旧帧自动区分并支持分包和粘包；一次采样请选用其中一种格式，避免重复上报。
扩展帧包含全部四路原数据和推杆反馈，不会把过期的旧值拼接成新的完整采样。
日志文本仍可在完整帧之间输出，不要插入二进制帧中间。

例如破碎率 2%、含杂率 3%、实际/目标转速 140/150 rpm、推杆 42.5%、伸出中：

```python
import struct
packet = struct.pack("<BfffffBB", 0xFE, 0.02, 0.03, 140.0, 150.0, 42.5, 2, 0xEE)
```

单片机尚未按扩展格式上报时，推杆区域显示暂无数据。

## 清理历史会话

“采集会话 → 清理历史会话…”或文件菜单提供清理入口。先显示**已配置记录目录**、
历史会话数量、文件数量和总大小，详情可查看文件名；默认按钮和 Escape 均为取消。
只有点击“确认删除”才永久删除，程序内不提供撤销。

清理范围为该目录第一层中有效的 `.swave` 及各自的 `.swave.events.jsonl`。
当前正在记录或打开的会话、后台导出/历史读取/测量读取使用中的会话、子目录、符号链接、未知格式
或损坏会话，以及 CSV/JSON/PNG 等导出文件均保留。散落在其他目录的会话不会清理。
确认期间新增或发生变化的文件会保留；删除前重新检查保护列表和文件快照。
删除失败会列出具体文件；若仅配套事件删除失败，会保留该文件并明确报告。

## 热插拔与重连

- 未连接时每 1.5 秒自动刷新端口，展开下拉列表时暂停刷新，保留当前选择。
  插入设备后无需手动刷新；端口消失时不会自动选择其他设备。
- “异常断开后自动重连”默认关闭，勾选后仅在本次已连接的设备异常断开时等待并重试。
  不会在启动软件时自动连接；手动断开、取消重连或取消勾选均会结束重试。
- 优先使用唯一设备序列号并核对已知 VID/PID，端口号变化也可识别；多个候选使用
  同一序列号时不自动连接。设备没有序列号时只尝试原端口及已知 VID/PID，
  无法区分占用同一端口的同型号替换设备。将鼠标停在 VID:PID 上可查看序列号说明。
- 重连成功后建立新采集会话；旧会话保留断开事件，不将两次采集拼成连续数据。

## 通道与坐标

“通道与坐标”可单独显示/隐藏五条曲线、更改颜色，或为三幅图分别设置固定
Y 轴范围。隐藏只影响绘图，原始数据、统计和导出仍完整保留。
品质和转速的 Y 自适应只考虑可见曲线；推杆在自适应模式下固定为 0～100%，避免视觉上超程。
手动固定范围的最大值必须大于最小值。
设置会保留，也可恢复默认颜色、全部通道显示和 Y 自适应。
取消设置不应用修改。Ctrl+滚轮、Shift+拖动调整出的手动 Y 轴范围也会保留。

## 会话事件与备注

- 开始/停止记录、传感 CAN 或串口的连接/断开会自动记录为事件。传感设备连接期间，完整排队的控制台命令也会记入会话。
  “添加备注”记录当前主机时间，可以在实验时标注操作或观察结果。
  事件与采样共用同一个主机单调时钟起点；命令事件仅代表发送排队，不代表设备执行成功。
- “事件”打开实时更新的列表，双击一行跳到对应波形时间。当前范围最多显示最后
  32 个事件标记，密集标记减少文字重叠；完整内容始终在列表里。
  停止记录后仍可追加操作事件与备注，历史打开的会话保持只读。
- 事件保存在同目录的 `会话名.swave.events.jsonl`，每个事件及时刷新。
  手动移动或备份时请连同 `.swave` 一起复制；“会话另存为”会复制波形和事件。
  CSV / JSON 数据导出仍只包含采样，不包含事件。
- 旧会话没有配套文件时照常打开。未写完的最后一行事件在恢复时忽略；完整行损坏、
  格式版本不支持或会话起点不匹配时明确提示，波形仍可查看，不将错误事件混入会话。
  配套事件读取失败时不提供完整会话另存，可先检查配套文件或导出采样数据。
- 每个会话最多 100000 个事件，单条内容最多 2048 字符，较长命令事件仅保留前段。
  事件写入失败时停止记录并提示，待写事件保留在内存中；可以修复后重试或另存恢复。
  另存时若波形已保存而事件失败，当前路径会显示新的波形路径，仍可再次另存到其他位置。

## 控制台调试

- “控制台配置”下的 UART 和 CAN 各自选择接口并连接，可同时在线。右侧控制台在同一排提供“UART”“UART 终端”“CAN”。
  选择 UART 或 CAN 可看到对应的发送区和共享日志，选择 UART 终端可使用整块控制台区域。收发日志用 `[UART]`、`[CAN]` 区分。
  控制台连接可以独立于传感采集使用。
  传感 CAN 和控制台 CAN 可使用同一个 CAN 接口；传感 UART 和控制台 UART 同时使用时需选择不同串口。
- 在“控制台配置 → UART”连接设备后，右侧选择“UART 终端”，点击终端即可向下位机 Shell 逐键输入。
  回车默认发送 CR，可切换到 LF 或 CRLF。退格默认发送 DEL，也可切换到 BS。终端显示设备返回的回显和输出，
  支持方向键、Tab、退格、Ctrl+C、UTF-8 和常用 ANSI 颜色、清行、清屏序列。
  终端聚焦时 Ctrl+字母交给下位机。Ctrl+Shift+C 复制选中内容，Ctrl+Shift+V 粘贴。
  终端保留最近 2000 行，新连接会清屏。日志的接收显示设置独立于终端。
- CAN 命令使用经典标准数据帧。按目标设备填写十六进制“发送 ID”，范围 `000～7FF`，可加 `0x`，首次默认 `401`，之后记住上次成功发送的 ID。
  字节 0 是命令号，可填十进制 0～255 或带 `0x` 的十六进制；
  字节 1～7 是由设备协议定义的 HEX 参数，可留空。每两位代表 1 字节，支持 `AA 55` 或 `AA55`，不加 `0x`。
  控制台实时显示发送 ID、参数字节数和 DLC。例如发送 ID `650`、命令号 `0x01`、参数 `AA 55`，DLC 为 3，
  发送报文 `650#01AA55`。完整排队后写入 TX 日志，设备执行结果由下位机协议确认。
- CAN 发送区的“进制转换…”可双向转换无符号整数，也可按选定字节长度和大小端格式复制 CAN 参数。
  例如十进制 `1500` 等于十六进制 `5DC`，选 2 字节时大端为 `05 DC`、小端为 `DC 05`。
  字节长度和字节序按下位机定义选择。
- 控制台 CAN 的回复 ID 使用 11 位标准帧，按十六进制填写 `000～7FF`。支持多项，例如 `651, 652, 7FF`，
  可加 `0x`，以逗号或空格分隔，重复 ID 会合并。最多可筛选 512 个不同 ID，留空接收所有标准数据帧。
  断开控制台 CAN 后可以修改列表。接收日志逐帧显示 ID、DLC 和 HEX 数据，每约 100 毫秒最多展示 64 帧。
- 串口发送支持 UTF-8 文本与 HEX；文本可选择 CRLF、LF、CR 或不加结尾。
  HEX 接受 `AA 55 01` 或 `AA5501`，不加 `0x`，不追加换行；奇数字符或非十六进制输入不会发送。
  下方显示实际字节数，文本模式包含结尾字节。发送日志的“已排队”不代表设备已确认执行。
- 未连接时也可编辑串口命令。“收藏”保存名称、内容、模式和结尾设置，最多 30 条；同名收藏会更新。
  收藏、历史选择只填入编辑框，须手动回车或点击发送。“发送后保留”方便手动重复发送。
- 日志支持关键字（不区分大小写）、级别、RX / TX / 系统来源筛选；Ctrl+F 打开控制台并聚焦搜索。
  支持自动换行与跟随滚动。向上滚动查看旧日志会取消跟随，可勾选“跟随”回到底部。
- “冻结日志”保留当前日志快照，控制台收发、波形和记录继续；恢复后显示最新缓冲。
  筛选与冻结都不会中断采集。日志缓冲最多 2000 条，单条文本超过 4096 字符会截断。
- UART 接收显示可选文本或原始 HEX。“关闭接收日志”同时隐藏 UART 和 CAN 接收日志。
  文本按换行分组；没有换行时等待约 200 毫秒空闲后显示，分包的 UTF-8 字符会等待完整。
  HEX 按约 100 毫秒合并展示，每批最多展示 512 字节，超量会提示省略数；传感采集独立进行。
  日志中的时间为生成日志的时间，HEX 批量显示不能用作精确设备采样时间。
- “保存…”可选择保存当前筛选或全部缓冲；冻结时当前筛选保存冻结快照，全部缓冲保存最新内容。
  保存前会先收取尚待显示的完整文本和 HEX 批次。保存使用原子替换，失败不会覆盖已有文件。
- F1 或“帮助 → 操作说明与快捷键”可查看程序内说明。

## 保存与导出

- 原始会话每秒或每累计 64 KB 刷新一次，并在停止、断开和正常退出前刷新。
  默认目录是 `QStandardPaths::AppLocalDataLocation/sessions`；Linux 通常为
  `~/.local/share/SerialWave/Serial_Wave/sessions`，以界面显示路径为准。
- `.swave` 是持久文件，关闭程序不会删除。文件名包含毫秒时间和随机后缀。
  强制结束进程可能丢失尚在内存中的记录；重新打开时会忽略末尾未写完的记录。
  这不等同于断电保护或物理磁盘同步保证。
- 写入失败会停止追加并明确提示，防止内存缓冲持续增长。可以修复磁盘后重试，或
  用“会话另存为”把已保存记录和内存中的待写入记录一并保存到其他磁盘。
  未成功保存时，正常退出会被阻止。
- CSV / JSON 导出在后台进行，支持进度和取消。导出的是**点击时的记录快照**，
  采集可以继续。取消或失败不会替换已有的目标文件，也不会修改原始会话。
- 新会话 CSV 列：`time_s,crush_rate,impurity_rate,motor_speed,target_speed,actuator_position_pct,actuator_state,received_at_utc`。
  JSON 包含版本、时间来源、UTC 会话起点以及 `samples` 数组，推杆状态为下文的数字代码。
  缺失推杆反馈在 CSV 中留空、JSON 中为 `null`，区间统计只统计有效值。
  旧四路会话仍按旧六列 CSV 导出，不伪造推杆数据。
- 新建 `.swave` 使用版本 2 的六路记录（时间 + 四路数据 + 推杆行程 + 状态，均为小端 double）；
  版本 1 的四路记录仍可打开。打开旧文件后新建会话会自动使用版本 2。
- “断开时导出 CSV”只控制额外的 CSV 导出；原始会话始终保存。
  关闭程序会保存原始会话并取消尚未完成的导出，可下次打开会话重新导出。
- PNG 导出包含三幅波形，尺寸为 1600 × 1500。

## 时间和状态的含义

协议没有设备时间戳。横轴使用本次会话起点之后的**主机单调接收时间**，
横轴最小为 0 秒，拖动和滚轮缩放均不会显示负时间。
停止上报的间隔会保留；CSV 的 UTC 时间由会话 UTC 起点加此偏移换算。
它不能恢复设备实际采样时刻：同一批到达的多帧可能集中在很短的时间内。
图中超过 2 秒的上报间断在细节视图中显示为断线；宽视图会合并小于一个绘图桶的间断。

界面区分未连接、等待数据、数据超过 2 秒未更新、电机运行/停止和暂无电机数据。
断线或过期时保留最后的数值和更新时间，但数值变灰，避免将旧值误认为实时状态。
平均值统计本次会话开始后的有效接收帧，停止记录后实时监测仍会更新。
协议没有电流字段，原来的空电流卡片改为“转速偏差”（实际值减目标值）。

历史加载在后台进行，显示按时间桶保留各通道极值，控制长记录的绘图内存；
归档和导出不抽稀，区间统计也使用原始数据。
